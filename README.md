# Tabela de Jogos Kings League Brazil - **Split 1** - Temporada 2024/25

Este projeto é uma aplicação web simples desenvolvida com **Flask** para exibir a tabela de jogos da **Split 1** da temporada **2024/25** da **Kings League Brazil**. Com um design simples e funcional, ele exibe as partidas, incluindo informações como times, placares, horários e o status de cada jogo (agendado ou finalizado).

### 🚀 Funcionalidades

A aplicação possui as seguintes funcionalidades:

- Exibição da tabela de jogos por rodada.
- Destaque para o time vencedor nos jogos finalizados.
- Exibição das logos dos times ao lado de seus respectivos nomes.
- Suporte para jogos agendados e finalizados.

### 🛠️ Pré-requisitos

Para rodar o projeto, você vai precisar de **Python 3.8+** instalado em seu computador, além de **Flask**, que pode ser facilmente instalado via `pip`.

### 📦 Como Executar

1. **Clone o repositório** para o seu ambiente local:

    ```bash
    git clone https://github.com/seu-usuario/flask_tabela_jogos.git
    cd flask_tabela_jogos
    ```

2. **Instale as dependências** necessárias com o seguinte comando:

    ```bash
    pip install flask
    ```

3. **Inicie o servidor Flask**:

    ```bash
    flask run
    ```

4. Por fim, acesse o aplicativo no seu navegador em **http://127.0.0.1:5000** para visualizar a tabela de jogos da **Kings League Brazil**.

### 🔧 Tecnologias Usadas

- **Backend**: Python com **Flask**.
- **Frontend**: HTML, CSS e JavaScript.

Agora, você terá a tabela de jogos da **Kings League Brazil** rodando localmente, pronta para acompanhar os resultados dos jogos. 🎮⚽
